# 💎 Diamond Dash 26 Web Game

เกมเว็บ Diamond Dash สไตล์อาร์เคด แนวนอน & แนวตั้ง รองรับมือถือและคอมพิวเตอร์อย่างลื่นไหล

## 🎮 โหมดการเล่น (Game Modes)

### 1. ⚡ โหมดคลาสสิก (Classic Mode - 60s)
- เก็บคะแนนให้ได้มากที่สุดภายใน **60 วินาที**
- **Tap to Match**: กดกลุ่มเพชรสีเดียวกันติดกันตั้งแต่ 3 ตัวขึ้นไป
- **ระบบ Combo**: ทุกการกดสำเร็จเพิ่มคอมโบต่อเนื่อง (รีเซ็ตถ้าไม่กดเกิน 1.5 วินาที)
- **💥 สกิลระเบิด (Bomb Mode)**: เมื่อทำคอมโบติดกันครบ **12 ครั้ง**
  - บล็อกที่กดจะระเบิดเป็นวงรอบจุดที่กด ทำลายเพชรทุกสี
  - รัศมีระเบิดขยายใหญ่ตามความยาวของบล็อกที่กด
  - สกิลทำงาน 3.0 วินาที (+0.3 วินาที ต่อคอมโบถัดไป)
  - เลขคอมโบจะยังคงนับต่อไปเรื่อย ๆ แม้สกิลจะหมดเวลาแล้ว
- **ระบบคำใบ้ (Hint)**: หากไม่กดเกิน 2.2 วินาที ประกายดาวจะวาบขึ้นบอกตำแหน่ง

### 2. 🌸 โหมดเซน (Zen Mode - Endless & Progression)
- **เล่นชิล ๆ ไม่มีเวลาจำกัด**
- เริ่มต้นจากตารางขนาดเล็ก **6×7 ช่อง**
- สะสมจำนวนบล็อคที่ทำลายตามเควสเพื่อเลเวลอัป
- กระดานจะค่อย ๆ ขยายใหญ่ขึ้นเรื่อย ๆ จนถึงขนาดตันที่ **20×20 ช่อง**!
- ระบบบันทึกเซฟความคืบหน้าอัตโนมัติ (เล่นต่อจากเดิมได้ตลอดเวลา หรือเลือกล้างเซฟได้)

## 🗂️ Assets & ฟอนต์
- **Gems**: เพชร 5 สี (`fire`, `moon`, `plant`, `thunder`, `water`)
- **Element**: เอฟเฟกต์ประกายดาวแตก `got.mov` / `got_spritesheet.png`
- **Fonts**:
  - ภาษาอังกฤษ & ตัวเลข: `Stratum No.1`
  - ภาษาไทย: `Hinn`
- **SFX**: เสียงประกอบครบถ้วน (`lost combo`, `Result`, `10 sec sfx`)

## 🚀 วิธีเล่น
เปิดไฟล์ `index.html` บนเบราว์เซอร์ Google Chrome, Microsoft Edge, Safari หรือเบราว์เซอร์ใดก็ได้
